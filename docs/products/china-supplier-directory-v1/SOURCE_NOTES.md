# Source Notes

This file records source evidence used before a supplier can be included in the paid PDF.

## Source Standard

Preferred sources:

- official company website,
- official contact/support page,
- official catalog/download page,
- official newsroom/about page,
- regulatory or exchange filings for public companies where useful.

Avoid as sole evidence:

- scraped B2B directories,
- copied marketplace listings,
- random phone-number pages,
- unaffiliated blogs,
- social profiles not linked from an official site.
