# GitHub release — 14 September 2026

Scope: all pending Sure Imports, Admin, Affiliate, Partner and LineScout application changes, including international PayPal checkout/refunds, partner UK billing/settlement, affiliate visibility/attribution and UI refinements.

Release checks: 288 Sure Imports tests, 119 Admin tests, 9 Affiliate tests, 164 Partner tests and 44 LineScout tests passed (624 total). All five clean production builds passed. Main-site TypeScript was checked separately because its build skips type validation. The four Prisma-backed projects validated and regenerated their clients successfully; no migration was applied during this release.

Partner's missing Sure Imports PayPal configuration was added to Vercel Production and Preview. Subscription lifecycle and sale events were added to the existing main-site PayPal webhook without removing existing event subscriptions. No charges, refunds, subscriptions or payouts were initiated for release verification.

LineScout's automatic home-screen installation prompt was removed from the root layout and its component deleted, with a regression test. Existing installed apps and service-worker functionality were not removed.

Old commented database URLs were removed from three Prisma schemas. Runtime connections still use DATABASE_URL. Historical Git revisions may retain these old strings; rotation/history cleanup is a separate security follow-up.

Deployment must use GitHub pushes to the already-linked production branches. Live human payment acceptance remains governed by the existing human-testing checklists, not implied by successful builds or mocked tests.
